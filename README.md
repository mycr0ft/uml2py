# uml2py

Clean-room Python implementation of the **UML 2.5.1 metamodel** and the **SysML v1 → v2
transformation**, generated from OMG-published XMI and validated against the
[sysmlpy](https://github.com/mycr0ft/sysmlpy) v2 reader.

No vendor tooling, no UML/SysML libraries — the generated packages are pure
stdlib, and every semantic in them is traceable to an OMG document.

## What's inside

| Piece | What it is | Checks |
|---|---|---|
| `gen/uml25.py` | UML 2.5.1 metamodel as Python classes — generated by `generate.py` from the OMG UML XMI: 242 metaclasses, 620 reference descriptors, 22 derived unions computed at read time, 328 hidden association ends (the subset/redefine lattice is closed by the generator), 449 OCL constraints carried as metadata | `check.py` 45 |
| `gen/standard_profile.py`, `gen/sysml.py`, `gen/uaf.py` | StandardProfile + SysML v1 + UAF 1.2 profile stereotypes (33 + 56 + 256 stereotypes), generated by `generate_profiles.py`; stereotypes fold their base metaclasses via Python inheritance, including cross-profile folds (UAF generalizes SysML stereotypes, e.g. `Capability(sysml.Block, ...)`) | `check_profiles.py` 40 |
| `v1_to_v2.py` | Clean-room SysML v1 → v2 **textual-notation emitter** anchored to OMG *SysML v2.0 Beta 4, Part 2: SysML v1 to SysML v2 Transformation* (ptc/2025-04-07). Every emitted form is calibrated against sysmlpy; anything without a normative mapping **raises `UnmappedFeature` instead of guessing** | `check_v1_to_v2.py` 47 |
| `xmi21.py` | XMI 2.1/EMF instance reader (dialect-tolerant: unprefixed containment, EMF feature defaults, cross-file `href` markers, stereotype applications) → feeds the emitter end-to-end | `check_dodaf.py` 32 |
| `xmi_write.py` | XMI 2.1/EMF instance writer — the read/write pair round-trips the OMG-published UPDM example with **canonical structural parity** (`canon.py`); reuses reader ids, emits applications + profile applications, skips containment opposites and EMF feature defaults | `check_xmi_write.py` 26 |
| `gen/bpmn.py` | BPMN 2.0.2 metamodel — OMG publishes BPMN as CMOF XMI (`BPMN20.cmof`), not a UML profile; `generate_bpmn.py` is a clean-room CMOF generator: 137 classes, 9 enums, 193 associations, opposite wiring, deliberately NOT UML Elements | `check_bpmn.py` 25 |

**215 checks, all green.** `REPORT.md` is the detailed build journal: dialect facts,
mapping tables with spec anchors, calibration evidence, and honest elisions.

## Quick start

The check suites for the metamodel and profiles are stdlib-only; the emitter
suites validate with [sysmlpy](https://github.com/mycr0ft/sysmlpy) (the
authoritative SysML v2 reader), and the generator/reader need `lxml`:

```bash
python check.py                 # UML metamodel: 45 checks (stdlib only)
python check_profiles.py        # profiles (Std + SysML + UAF): 40 checks (stdlib only)
python check_bpmn.py            # BPMN 2.0.2 CMOF metamodel: 25 checks (stdlib only)
~/sysmlpy/.venv/bin/python check_v1_to_v2.py    # v1->v2 emitter: 47 checks
~/sysmlpy/.venv/bin/python check_dodaf.py       # XMI end-to-end: 32 checks
                                #   (needs lxml + DoDAFLibrary.xmi, see REPORT Part 4)
~/ams-gra-sim/.venv/bin/python generate.py           # regenerate gen/uml25.py (lxml)
~/ams-gra-sim/.venv/bin/python generate_profiles.py  # regenerate the profiles (lxml)
```

The check scripts print every assertion; a failing assertion names the mapping.
`check_v1_to_v2.py` also writes `vehicle_example_v2.sysml`, `wave3_example_v2.sysml`,
and `wave4_example_v2.sysml` — worked examples of the emitted notation.

```text

generate_profiles.py   profile generator (StandardProfile.xmi, sysml.xmi, UAF.xmi -> gen/*.py)
gen/uml25.py           generated UML 2.5.1 metamodel (stdlib-only, self-contained)
gen/standard_profile.py  generated StandardProfile stereotypes
gen/sysml.py           generated SysML v1 profile stereotypes
gen/uaf.py             generated UAF 1.2 UAFML stereotypes (folds gen.sysml bases)
generate_bpmn.py       CMOF generator (OMG BPMN20.cmof -> gen/bpmn.py)
gen/bpmn.py            generated BPMN 2.0.2 metamodel (reuses gen.uml25 descriptors)
v1_to_v2.py            SysML v1 -> SysML v2 textual emitter (mapping authority: ptc/2025-04-07)
xmi21.py               XMI 2.1/EMF instance reader -> gen.uml25 objects
xmi_write.py            XMI 2.1/EMF instance writer (canonical parity vs OMG corpus)
canon.py                shared canonical XML comparator (writer oracles)
check*.py               six check suites (215 checks)
calibrate_v2.py        textual-form calibration harness for sysmlpy
REPORT.md              build journal: dialect facts, mapping tables, evidence
PLAN.md                plan for the exporter/QoL waves (E1-E6: XMI/CMOF/EMOF writers, stereotype writing, derived unions, query helpers)
```

## Clean-room discipline

- The generator and emitter are written from **normative OMG text only**
  (UML 2.5.1 XMI, profile XMI, the ptc/2025-04-07 transformation spec).
  Reference extractions and example XMI corpora are **kept out of the
  repository** (e.g. the local `transition.txt` spec dump is git-ignored).
- The only instance-model corpus used for reader tests is the
  OMG-published `DoDAFLibrary.xmi` (UPDM example). Third-party commercial
  book models are **excluded on copyright grounds**.
- The emitter follows an **honesty rule**: elements with no normative
  mapping raise `UnmappedFeature` naming the v1 metaclass rather than
  guessing, and spec gaps (e.g. ProxyPort, SYSML2_-329) surface as
  explicit comments.
